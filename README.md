# 🔍 Динамический "Умный поиск"

Этот репозиторий содержит исходный код для веб-приложения "Умный поиск" — инструмента, который динамически объединяет локальную базу данных о вселенной Disney с актуальной информацией из интернета.

Этот проект является частью большой [базы знаний о вселенной Disney](https://github.com/asakovic75/disney-knowledge-base).

## ✨ Ключевые возможности

- **Гибридный поиск:** Ищет совпадения одновременно в локальных CSV-файлах и во внешней базе данных TMDb.
- **Обогащение данных:** Автоматически подгружает постеры, сюжеты, биографии и фильмографии для записей из локальной базы, превращая их в полноценные информативные карточки.
- **Обнаружение нового:** Находит и отображает фильмы и актеров из интернета, которых еще нет в вашей локальной коллекции.
- **Интеллектуальная фильтрация:** Автоматически скрывает дубликаты, чтобы не показывать в результатах интернет-поиска то, что уже найдено в локальной базе.
- **Два режима поиска:** Позволяет искать отдельно по произведениям и по исполнителям.

## 🛠️ Технологический стек

- **Python:** Основной язык программирования.
- **Streamlit:** Для создания интерактивного веб-интерфейса.
- **Pandas:** Для загрузки и обработки данных из CSV-файлов.
- **TMDb API:** Внешний источник для получения динамических данных о фильмах и актерах.
- **Requests:** Для выполнения запросов к API.

## ⚙️ Как это работает

1.  Приложение загружает данные из локальных файлов `Произведения.csv` и `Исполнители.csv`.
2.  При поиске сначала ищутся совпадения в локальных данных. Для каждого найденного результата делается запрос к TMDb API для получения дополнительных сведений (постер, биография).
3.  Параллельно выполняется второй, независимый поиск по тому же запросу уже в TMDb.
4.  Приложение сравнивает результаты и отображает в разделе "Найдено в интернете" только те элементы, которые не были найдены в локальной базе.
